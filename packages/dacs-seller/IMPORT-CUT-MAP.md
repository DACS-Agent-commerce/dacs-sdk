## 1. Rules

- **Sources.** `DACS-Agent-commerce/frontend` main `82bf8c4` (the integration base) for `src/` and `test/`; #58's inspected head `786aa1d` and #59's inspected head `ffef873` for `port-sources/` (see `PORT-SOURCES.md`).
- **References followed.** Static `import` and `export … from`, `import()` with a literal specifier, and `new URL(<literal>, import.meta.url)`. In test files, relative path literals that name a file under `http-mcp/test/` too (child-process scripts, for example). The scanner is the TypeScript parser (`scripts/lib/source-graph.mjs`), not a regular expression.
- **Ownership** (the same rule for both step-1 packages):
  - a file named in §0.3's client row, or reached from those files' closure, belongs to `@kynesyslabs/dacs-client`;
  - a file named in §0.3's seller row belongs to `@kynesyslabs/dacs-seller`; if the client set holds it too, it is copied whole into both packages;
  - any other file the seller closure reaches that the client set holds is not copied into the seller: "from `@kynesyslabs/dacs-client` (shared)".

  Bare names in the client row resolve under `http-mcp/src/dacs/` (the client's `listing.mjs` is `src/dacs/listing.mjs`; the seller's is `src/devnet-demo/listing.mjs`), and its globs expand there: `*-consumer.mjs` gives 8 files and `delivery-*.mjs` gives 3. `src/devnet-demo/commitment-consumer.mjs` matches the glob's pattern in another directory; the client closure reaches it anyway, from `protocol-purchases.mjs:67`.
- **Closure stops.** External packages and Node built-ins; D1's cut list (`src/wallet/*`, `public/portal/*`, `buyer-access.mjs`, `operations.mjs`), except the six files §0.3 names (`src/wallet/devnet-native-transport.mjs`, `src/wallet/durable-journal.mjs`, `public/portal/embedded-wallet/sdk-provider.mjs`, `public/portal/seller-session-delegation.mjs`, `public/portal/seller-session-limits.mjs`, `public/portal-intent/intent.mjs`); D11's seams (`src/store/database.mjs`, `src/portal/*`); the in-process operator (`src/devnet-demo/{operator,operator-buyer,operator-buyer-approval,operator-buyer-run,operator-sessions,operator-network,seller-relay,composition,stop}.mjs`); relative `node_modules`/`dist` paths; and, for the seller, client-set files.
- **Path mapping** (a pure function of the source path, the same for both packages): `http-mcp/src/X` → `src/X`, `http-mcp/public/Y` → `src/public/Y`, `http-mcp/test/Z` → `test/Z`, and a PR file `P` → `port-sources/pr<N>-<head>/P`. A relative import between two copied files keeps resolving; one into `public/` from `src/` or `test/` would not (`public/` moves under `src/`), and none of those targets is copied into the seller.

- `src/dacs/fixture-anchors.mjs` (shared). - `src/devnet-demo/stop-request.mjs` (shared). The compose CLI's stop flag: 10 lines, import-free. It is in the client set only because the client closure enters `operator-approval.mjs`. If prep-ws4-step1's closure does not take it, the seller copies it instead.

- `src/wallet/durable-journal.mjs` is reached by no seller file. The in-process operator opens it (`operator.mjs:23`), so the seller host (`start`, D12) will need it from `@kynesyslabs/dacs-client`'s durable-journal subpath.
- Left-out tests that drive seller code without importing it (§6 G8). Step 1 selects tests by direct import, as the brief says. That leaves out 104 of the 255 tests even though their closure drives copied seller files: 78 through test helpers and 26 only through the copied `dacs-loopback-fixture.test.mjs`. 35 of the 78 reach a seller-only file, such as `operator-custody.mjs`, `party-vet-store.mjs` or `artifact-anchor.mjs`. Decision for step 1: none is copied, and each is mapped in G8 with its own decision:
  - 47 also drive the in-process operator. D12 re-hosts them on the seller host, or they stay in `http-mcp`.
  - 16 have their helpers copied already, so moving one adds only the test file.
  - 15 need their helpers copied too.
  - 26 go with the entry for `dacs-loopback-fixture.test.mjs`.

  Brief 4's "moved tests pass or are mapped" and its SIGKILL/restart acceptance should be measured against the copied tests plus G8. Widening the step-1 selection is a decision for the maintainers.
